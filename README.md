# Map-Editor
Map Editor — веб-редактор карт помещений с поддержкой 2D и 3D. Позволяет загружать растровые планы или рисовать схемы с нуля: стены, комнаты, двери, лестницы, мебель, сцены и стенды. Есть маркеры точек с фото и панорамами 360°, построение маршрутов в обход препятствий, роли администратора и пользователя. Данные хранятся в IndexedDB.
